# HTML-макеты: как не сломать

Макеты в `docs/design/*.html` рисуют экраны iPhone одним набором классов: `.phone-wrap`, `.phone`, `.island`, `.sb`, `.home`, `.mark`, `.ctl`, `.row3`, `.title`, `.topbar`. Правила этих классов задают абсолютное позиционирование и фиксированный размер 390×844.

## Поломка 22.09.2026

В `volna-confirm.html` подпись в списке шагов получила классы `who phone` (смысл: «шаг выполняет телефон»). Правило `.phone{position:absolute;width:390px;height:844px}` применилось и к ней: подпись стала пустым корпусом телефона поверх страницы, текст под ним не читался. Артефакт ломался так уже второй раз.

## Правила

- Классы корпуса телефона из списка выше зарезервированы. Для других смыслов бери другие слова: `dev`, `device`, `on-phone`.
- Правило корпуса пиши через родителя: `.phone-wrap > .phone{…}`, а не голое `.phone{…}`. Тогда случайный класс `phone` в другом месте ничего не сломает.
- Перед публикацией открой файл локально, посмотри один скриншот и проверь в консоли, что `[...document.querySelectorAll('.phone')].every(e => e.parentElement.classList.contains('phone-wrap'))` возвращает `true`, а `document.documentElement.scrollWidth` не больше ширины окна.

## Холст для новых дизайнов

С 25.09.2026 новый дизайн (экран, варианты решения) собирается на холсте: папка `docs/design/canvas/<тема>/`, каждая доска отдельным HTML («Сейчас», A, B…), раскладка в `canvas.json`. Порядок работы описан в пользовательском скилле `canvas` (`~/.claude/skills/canvas/SKILL.md`), CLI лежит там же, формат совместим с холстами Claude Desktop. Холст публикуется на https://draftwall.vercel.app (вход по паролю), там его смотрят с телефона и оставляют стикеры; `canvas pull` забирает их обратно. Правила выше действуют и для досок.
