Решения только с телефона

СТАТУС · ОДОБРЕНО И ВНЕДРЕНО 22.09.2026 · ВАРИАНТ Б · БЕЗ FACE ID · ПЕРВЫЙ СЛУЧАЙ: ДОВЕРИЕ ПАПКЕ В CLAUDE DESKTOP

Когда Волна открывает новый чат Claude, Desktop может спросить «Trust this workspace?». Нажимать «Trust» сам Пульт не должен, а голосу не верим: голос может быть не твой, а модель могла понять неверно. Решение уходит Волне, она просит подтвердить, а подтверждает только нажатие на экране телефона. Потом по тому же пути пойдут разрешения агентам (Bash, правка файлов).

Правило

Модель может попросить подтверждение, но выдать его не может. Инструмента «подтвердить» у модели нет. Подтверждение идёт по отдельному HTTP-маршруту от приложения на телефоне к ядру и дальше к Пульту, с токеном ядра из Keychain. Этот токен модель не видит. Фраза «да, подтверждаю» голосом ничего не делает: Волна отвечает, что нужно нажать кнопку на экране.

Как это происходит

Первый раз для папки. Если ты уже доверил её в Desktop, окна нет, и чат отправляется сразу, как сейчас.

  1. ТЫ«Открой новый чат Клода в CallAssistant: прогони тесты». Волна зачитывает промпт вслух.
  2. ВОЛНА → ПУЛЬТagents_start. Пульт открывает ссылку в Desktop и видит через Accessibility окно доверия с путём этой папки.
  3. ПУЛЬТЗаводит запрос: случайный id, тип «доверие папке», путь, срок 2 минуты. Модели возвращает только needs_confirmation и текст для тебя, без id.
  4. ВОЛНА«Desktop спрашивает, доверять ли папке CallAssistant. Подтверди на экране телефона».
  5. ТЕЛЕФОНВо время звонка приложение раз в 1,5 с спрашивает ядро о запросах (GET /confirmations, ядро берёт их у Пульта). Появляется карточка. Если экран заблокирован, приходит уведомление.
  6. ТЫ, ПАЛЬЦЕМ«Подтвердить» → POST /confirmations/{id} с токеном ядра. «Отклонить» закрывает окно в Desktop кнопкой Cancel.
  7. ПУЛЬТПроверяет, что окно всё ещё на экране и путь тот же, нажимает «Trust workspace», ждёт промпт в поле, нажимает Return и находит новую сессию. Если что-то не сошлось, ничего не нажимает и отвечает ошибкой.
  8. ВОЛНАЯдро сообщает ей результат заметкой в сессии: «Отправил в CallAssistant». Ответ Клода потом придёт в agents_list.

Карточка на экране звонка

Два места. А: карточка встаёт между статусом и знаком, знак уменьшается до 196 pt, клавиши остаются на месте. Б: то же, но карточка прижата к клавишам снизу, знак не двигается. Рекомендую А: карточка ближе к глазам, и её не перепутать с клавишами звонка.

Что считается подтверждением

ДействиеРезультат
Нажатие «Подтвердить» в карточкеПульт нажимает «Trust workspace», затем Return
«Да, подтверждаю» голосомНичего. Волна напоминает про кнопку на экране
«Отклонить» или 2 минуты без ответаПульт нажимает Cancel в Desktop, карточка гаснет с подписью «Отклонено» или «Время вышло»
Звонок завершён с открытым запросомЗапрос сгорает; окно в Desktop остаётся для решения за Mac
Окно в Desktop закрыли или сменился путь до нажатияПульт ничего не нажимает, карточка: «Окно на Mac уже закрыто»

Что меняется в коде

ГдеЧто
Pult · ConfirmationCenterочередь запросов (id, тип, путь, срок), поиск окна доверия и нажатие его кнопок через Accessibility; маршруты GET /confirmations, POST /confirmations/{id}
core · http/confirmations.tsпрокси для телефона с его токеном; после решения короткая заметка в сессию через sideband. Инструмента для модели нет
core · pult.tsagents_start возвращает needs_confirmation с текстом для пользователя, без id
iOS · ConfirmationClientопрос во время звонка, решение по нажатию; события CallEvent.confirmationRequested/Resolved через CallReducer
iOS · ConfirmationCardкомпонент в UI/Components, строки в CallCopy с unit-тестом, локальное уведомление при заблокированном экране
docsинвариант «решения только с телефона» в architecture.md, раздел безопасности; протокол в core.md
