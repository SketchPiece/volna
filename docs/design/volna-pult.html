Волна: Пульт

Фоновый пульт для всех агентов на этом Mac. Живёт в строке меню, следит за сессиями Claude Desktop, Claude Code и Codex, присылает уведомления, когда кто-то ждёт тебя или ход завершён, и открывает сессию в родном клиенте. Разговоры остаются в Claude и ChatGPT: чат-окна у Пульта нет по решению владельца 22.09.2026. Всё собрано из «Бакелита и лампы».

Состояние. Приложение собрано и работает на Mac владельца: панель ниже реализована в SwiftUI, окно настроек тоже. Здесь зафиксирован ориентир, чтобы сверять реализацию с дизайном.

01 · Лампы и состояния Lamp · StatusPill

Одна и та же лампа для обоих агентов, чтобы взгляд не переключался между вендорами. Красный не обозначает статус: он только на кнопке, которую нужно нажать.

02 · Панель в строке меню MenuBarPanel

Единственный экран Пульта. Показывает, кто ждёт, кто работает и кто в ожидании; иконка в строке меню несёт число сессий, которые ждут тебя. У каждой строки фирменный знак агента (Claude и OpenAI из Simple Icons), а во второй строке модель и уровень рассуждения: «Claude Desktop · Fable 5.1 · high · CallAssistant». Клик по строке открывает сессию в родном клиенте. Правки 22.09.2026 (зелёная лампа «работает», без «написать», настройки в три группы) в volna-pult-refresh.html, они актуальнее этого экрана. Кнопка «+» в шапке раскрывает форму новой сессии: агент (Claude / Codex вдавливанием), папка, текст; «Начать» запускает сессию силами Пульта: строка появляется в эфире, запрос разрешения показывается в ней кнопками «Разрешить/Отклонить», ответ приходит уведомлением и остаётся во второй строке; крестик убирает сессию из эфира, стрелка открывает её в родном приложении.

04 · Правила и решения

Что показываем честно

  • Источник сессии всегда подписан: Claude Desktop, Claude Code (CLI), Codex через ChatGPT.app, Пульт.
  • Сессия из Claude Desktop или ChatGPT.app в Пульте только читается и получает сообщения; вести её как свою нельзя, чтобы два процесса не писали один транскрипт. «Открыть» ведёт в родной клиент.
  • «Работает» для треда Codex значит «менялся последние две минуты»: живое состояние держит ChatGPT.app, Пульт видит только диск.
  • Сообщение в чужую сессию всегда по явному действию: оно начинает ход и тратит токены.

Что осталось решить

  • Автозапуск при входе в систему: после недели обкатки.
