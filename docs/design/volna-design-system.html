ВОЛНА-1

ГОЛОСОВОЙ ЗВОНОК · CALLKIT · SIRI · REALTIME

Приложение делает одно: по тапу или по фразе «Siri, позвони Волне» открывает голосовой разговор с AI. В центре внимания сама волна из знака. В покое это логотип. Когда Волна слушает, кольцо вокруг загорается янтарным. Когда Волна говорит, волна бежит и дышит по амплитуде голоса.

Корпус, тени, шрифты, лампы и красный сигнал взяты из драфта «Бакелит и лампа» без изменений. Радиошкала, стрелка и ручка из драфта не используются: в звонке им нечего показывать.

Знак на экране звонка: фаза «говорит», живая анимация

Что переложено из драфта

Одна метафора на всё приложение: Волна выходит в эфир. Всё, что было про приёмник и станции, убрано или отложено.

Знак-волна

Один компонент WaveMark в трёх размерах. Форма волны считается процедурно, поэтому в покое она совпадает с логотипом, а в речи оживает без подмены картинки.

lg · 236 pt · экран до звонка. В звонке xl · 272 pt, плоская тень (см. правки 22.09.2026). Покой = логотип.

md · 150 pt · экран «Голос», карточки состояний

sm · 96 pt · шапка листов. Иконка приложения: красный диск на корпусе.

Геометрия

  • Диск: корпус ivory с тенью raised-lg. Это тот же круг, что в знаке, только выпуклый.
  • Волна: линия signal, толщина 5.5 в viewBox 120, концы скруглены. Огибающая колокол с центром в середине, длина волны 36, максимум амплитуды 26.
  • Кольцо: пунктир 2/5 радиусом 50. В покое lampOff, при приёме lamp, при речи сплошное lampHot с пульсом.
  • Метка: точка сверху на кольце, как на ручке в драфте. Горит вместе с кольцом, при обработке бежит по кольцу.
  • Ниже 48 pt используется статичный логотип драфта: красный диск, волна корпусного цвета.
// UI/Components/WaveMark.swift
struct WaveMark: View {
  enum Size { case xl, lg, md, sm }      // 272 / 236 / 150 / 96; xl и lg с плоской тенью
  var phase: CallCoordinator.Phase
  var isMuted: Bool
  var level: Double = 0                   // 0…1, амплитуда голоса
  var body: some View {
    TimelineView(.animation(minimumInterval: 1/30, paused: !animates)) { tl in
      ZStack {
        Circle().fill(Volna.Color.ivory).raised(.lg)
        Ring(state: state)                  // пунктир / сплошное / лампа
        WaveShape(t: tl.date, amp: amp, travel: travel)
          .stroke(Volna.Color.signal, style: .init(lineWidth: 5.5, lineCap: .round))
      }
    }
  }
}
// WaveShape: path из 45 точек, y = 60 − 26·amp·exp(−2.8u²)·sin(k(x−62) + travel·t)
// amp по фазе: idle 1.0 · connecting 0.35 · listening 0.6 + 0.15·sin(1.6t)
//              thinking 0.4 · speaking 0.55 + 0.6·level · muted 0.08 · failed 0.15 + шум

Компоненты

Живые образцы. Все интерактивные элементы не меньше 44 pt. Нажатие переводит выпуклую тень во вдавленную.

Статус-пилюля и лампы StatusPill · Lamp

Лампа горит только когда Волна реально слышит или говорит. Мигает только при соединении.

Кнопки SignalButton · RaisedButton · QuietButton

перебивание голосом

SignalButton один на экран. Тихая кнопка без тени для второстепенных действий во время звонка.

Клавиши управления звонком RoundControl · EndCallButton

Вдавленная клавиша = включено (динамик). Иконка вдавленной клавиши окрашивается в сигнальный, как в драфте для :active.

Состояния знака

Семь фаз из CallCoordinator.Phase плюс mute. У каждой своя форма волны, своё кольцо и свой текст. Все образцы живые.

Экраны

Базовый размер 390 × 844, поля 24 pt. Знак в центре, статус наверху, кнопки внизу в зоне большого пальца. Экран звонка без прокрутки.

Правки 22.09.2026 (внедрены): статусы в звонке односложные с иконкой («Соединяю…», «Слушаю», «Думаю», «Говорю»), знак в звонке 272 pt с плоской тенью, метка «думаю» 9 с/оборот и плавный возврат наверх при выходе из фазы, ряд клавиш Микрофон (52) · Завершить (72) · Стенограмма (52), клавиш «Динамик» и «Аудио» нет: громкая связь по умолчанию, у уха переключается датчик. Лист «Стенограмма» показывает всю историю реплик. Макеты экранов 02–04 и 09 ниже устарели в этих деталях; актуальные в volna-call-refresh.html.

Доступность и тесты

Что сохраняем

  • Все accessibilityIdentifier без изменений, UI-тесты остаются зелёными: settings, callStatus, callError, mute, endCall, startCall, voicePicker, serverURL, connectionResult, preview.
  • callStatus остаётся на подзаголовке и продолжает отдавать call.status. Статус-пилюля добавляется отдельным элементом.

План внедрения в SwiftUI

Четыре шага, каждый собирается и проходит тесты отдельно. Логика CallCoordinator не меняется.

Шаг 1 · Фундамент

  • Resources/Fonts/: Unbounded, IBM Plex Sans, IBM Plex Mono (.ttf, OFL) + UIAppFonts в Info.plist. Обновить scripts/generate-project.rb.
  • Resources/Colors.xcassets: 12 цветов драфта.
  • UI/Theme/WaveTheme.swift: токены, Font-роли, модификаторы raised / pressed.
  • Иконка приложения: красный диск с волной на корпусе.

Шаг 2 · Компоненты

  • UI/Components/WaveMark.swift: WaveShape (процедурная волна), кольцо, метка, состояния по фазе. Заменяет VoiceMark.
  • UI/Components/: Lamp, StatusPill, SignalButton, RaisedButton, QuietButton, RoundControl, EndCallButton, VoiceRow, AnswerCard, PressedField, SettingsGroup, ErrorCard, SiriCard.
  • Уровень голоса для знака: новый @Published level в RealtimeClient от локального и удалённого трека. До этого синтетика.

Шаг 3 · Экраны

  • CallView: переписать вёрстку на компоненты, состояния по таблице. Идентификаторы сохранить.
  • SettingsView: с Form на кастомный ScrollView с группами. Логика check/save без изменений.
  • Новый VoicePickerView: знак в фазе «говорит» + список голосов, замена Picker(.navigationLink). Идентификатор voicePicker на строке «Голос».
  • TranscriptSheet и AudioRouteSheet вместо системных sheet-текста и confirmationDialog.

Шаг 4 · Проверка

  • UI-тесты 3/3, тесты ядра 9/9, сборка Simulator.
  • Снимки экранов idle / connecting / speaking / failed / settings в Simulator для сверки с этим документом.
  • Dynamic Type xxxLarge и iPhone SE: экран звонка без прокрутки.

Вопросы на одобрение

Ответы меняют вёрстку, поэтому нужны до начала кода. По каждому есть рекомендация.

#ВОПРОСРЕКОМЕНДАЦИЯ
1Знак на экране звонка: выпуклый диск корпуса с красной волной (как здесь) или красный диск с волной цвета корпуса, как иконка приложения?Диск корпуса: красный остаётся за кнопкой, знак не спорит с CTA, а лампа-кольцо читается.
2Обращение «ты» по драфту или «вы», как сейчас в приложении и в характере Волны с «товарищ»?«Ты» в интерфейсе по драфту, характер голоса Волны не трогаем.
3Светлый корпус основной, тёмный бакелит фаза 2. Или сразу поддержать обе темы по системной настройке?Сначала светлый. Тёмный после того, как светлый проверен на iPhone.
4Кастомный экран настроек вместо системного Form. Больше кода, полный контроль над видом.Кастомный, иначе настройки выпадают из стиля.
5Реальная амплитуда голоса для знака требует доработки RealtimeClient. Делать в этой итерации или оставить синтетику?Сначала синтетика, амплитуду отдельной задачей.
