# Звуки Волны

Звуки синтезируются в коде, файлов в приложении нет. WAV здесь только для прослушивания; громкость в них как в приложении.

## Звук ожидания звонка (в приложении)

`call-wait.wav`, код `ios/CallAssistant/Domain/Call/Ringback.swift`, как играет — [architecture.md](../../architecture.md), раздел про звук ожидания. Одобрен владельцем 26.09.2026 (вариант B из шести).

- Тихий шум эфира без перерыва: белый шум через два однополюсных фильтра (коэффициенты 0,08 и 0,5), уровень 0,12, медленно «дышит» ±15 % за круг.
- Каждые 4 с «тин-тин»: чистый синус 523 Гц, подъезд на ноту с 3 % ниже (0,06 с), атака 15 мс, затухание exp(−t/0,5); эхо той же ноты через 0,35 с на уровне 0,25.
- Громкость плеера 0,18. Шум появляется из тишины за 0,6 с до первого «тин-тин» и доходит до 40 % громкости, затем за 8 с (два круга) нарастает до полной. На ответе Волны звук гаснет за 1 с под её голосом, при отбое обрывается за 30 мс (с 26.09.2026).

Отвергнуты: гудки 425 Гц (1 с через 4 с); «настройка на станцию» со свистом и треском («слишком напряжённо»); первый «тин-тин» 660 Гц с октавой и шумом 0,45 при громкости 0,45 («очень громко»).

## В запасе
