Экран управления тем, что Волна помнит о хозяине. Ядро уже ведёт память (транскрипты, извлечение после звонка, «сон»). Экран показывает её и даёт четыре рычага: уровень близости, чувствительные темы, удаление записи, «забыть всё». Разовый «звонок без памяти» не делаем: переключение на «Холодную» занимает один тап.

Новых цветов, теней и шрифтов нет. Новые компоненты: строка уровня с описанием (расширение SelectableRow), строка записи с меткой вида, карточка профиля на стекле.

Поведение

  • Уровень применяется сразу: тап шлёт PUT /memory/settings, строка вдавливается без ожидания ответа, при ошибке возвращается и показывается карточка ошибки.
  • Во время звонка уровень менять нельзя (строки приглушены, как голоса): он уже вшит в сессию.
  • Список загружается при открытии и обновляется pull-to-refresh. Кэша на телефоне нет: если ядро недоступно, показывается только ошибка.
  • Удаление записи закрывает её в ядре (она остаётся в истории для recall), в списке исчезает сразу.
  • Идентификаторы доступности для тестов: memory, memoryLevel, memoryProfile, memoryList, forgetAll.

Решения владельца · 22.09.2026

  1. Профиль на стекле. Принято: профиль считается текстом Волны и живёт на стекле.
  2. Два красных. Принято: «Забыть всё» и свайп оба красные. Клавиша свайпа круглая, не прямоугольная.
  3. Техническая информация. Вместо постоянной строки «Ядро» группа «Отладка», видимая только при включённом режиме отладки в настройках.
  4. Ручное добавление записи. Не делаем.
