# Иконка «Штурвала»

«Штурвал» — Mac-приложение владельца для управления работой, которую запускает Волна (своя замена T3 Code). Иконка одобрена 27.09.2026: вариант Е2·2 «Круглый экран» с холста [helm-icon](../../canvas/helm-icon) (доска `j2-round.html`).

Смысл: волна из знака Волны переходит в цифровой сигнал (голос стал работой) и горит янтарём на круглом экране лампового осциллографа.

## Файлы

| Файл | Для чего |
| --- | --- |
| `helm.svg` | Исходник. Полный квадрат без скругления, viewBox 120. Править только его. |
| `AppIcon-1024.png` | 1024×1024, без прозрачности и скругления: для iOS asset catalog и как исходник для других сборок. |
| `AppIcon.icns` | Для macOS (16–1024 px, @1x и @2x). Уже с полями и скруглением по сетке macOS: квадрат 824/1024, радиус 184. |
| `make-icons.sh` | Пересобирает PNG и icns из SVG: `sh docs/design/icons/helm/make-icons.sh` (нужен Google Chrome). |

В Mac-приложении: положить `AppIcon.icns` в `Resources` и указать `CFBundleIconFile = AppIcon` в Info.plist (как делал Пульт, см. `archive/pult/scripts/build-pult-app.sh`). Для Xcode-проекта с asset catalog взять `AppIcon-1024.png` (одноразмерная иконка macOS).

## Устройство

Цвета из дизайн-системы «Бакелит и лампа» ([volna-design-system.html](../../volna-design-system.html)):

- фон — signal `#B8321F` (красный);
- экран — круг r=44 в центре, bakelite `#26211D`, обод ivory `#E7E0D2` толщиной 3;
- сетка — линии ivory с прозрачностью 0.1, толщина 1.2, на 38/60/82 по обеим осям, обрезана кругом r=41;
- сигнал — lamp `#E8A33D`, линия 5.5, круглые концы, лёгкое свечение (drop-shadow 1.5, тот же янтарь). Путь (масштаб 0.95 от центра):
  `M26 60 Q30 50 34 60 Q38 70 42 60 Q46 50 50 60 Q54 70 58 60 L58 47 L70 47 L70 73 L82 73 L82 60 L93 60`.

Семья с иконкой Волны (светлый фон, красный диск, кремовая волна): та же сетка 120 и диск r=44, но цвета наоборот, поэтому в доке их не спутать.

Не делать: не добавлять текст и детали (ручки, шкалы) — в 16–32 px они сливаются; не менять янтарь сигнала на другой цвет — лампа единственный акцент.
