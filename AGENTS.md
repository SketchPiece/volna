# Волна: инструкции для агентов

Этот файл короткий намеренно. Не расширяй его описаниями: добавляй только ссылку на документ, где факт уже зафиксирован, и одну строку, зачем он нужен. Подробности живут в `docs/`.

## Что это

Нативное iOS-приложение (SwiftUI, CallKit, SiriKit, WebRTC): один тап или «Siri, позвони Волне» открывает голосовой разговор с AI через OpenAI GPT-Live (полный дуплекс; с 22.09.2026, до этого Realtime). Ядро на Node держит ключ. Прототип для одного пользователя.

## Команды

```sh
cd core && npm test                                   # 390 тестов ядра (1 в todo до решения по эксперименту 363cc0e); npm run typecheck; npm run metrics — сводка задержек звонков
cd ios && xcodebuild -project CallAssistant.xcodeproj -scheme CallAssistant \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' -derivedDataPath build test   # 84 unit + 5 UI, с подписью для симулятора
cd relay && node --test 'src/**/*.test.ts'           # тесты «Узла»; ./launchd.sh install | status — LaunchAgent на Mac
ruby ios/scripts/sync-project.rb                        # после добавления, переноса или удаления Swift-файлов
```

Без подписи (`CODE_SIGNING_ALLOWED=NO`) приложение падает при старте: нет Siri-entitlement. Причина и обход в [docs/architecture.md, раздел 9](docs/architecture.md#9-тестирование).

## Жёсткие правила

- Ключ OpenAI никогда не попадает в клиент, репозиторий или логи. Токен ядра только в Keychain.
- Не менять идентификаторы доступности и проверяемые тестами строки без правки тестов. Список в [docs/architecture.md, 4.3](docs/architecture.md#43-что-не-меняем).
- Новые Swift-файлы регистрировать `ruby ios/scripts/sync-project.rb`; шрифты и каталоги также в `ios/scripts/generate-project.rb`.
- Состояние звонка меняется только через `CallEvent` и `CallReducer`; побочные эффекты только в сервисах. Новый текст фазы идёт в `CallCopy` с unit-тестом.
- Не описывать поведение как проверенное на iPhone, если оно проверено только в симуляторе.
- Изменил границы модулей, потоки или инварианты: обнови `docs/architecture.md` в том же изменении. Изменил интерфейс: обнови дизайн-документ и прогони `DesignScreenshots`.
- Работа идёт в ветке задачи, не в `main`; коммить по ходу, не оставляй работу незакоммиченной. В коммит только свои файлы; чужие незакоммиченные правки в рабочем дереве не трогать и не включать. Задача заканчивается PR после самопроверки; после зелёного CI агент мержит его сам, если владелец не просил остановиться на PR ([docs/ci-cd.md](docs/ci-cd.md)).
- Сюда и в `CLAUDE.md` добавлять только ссылки. Новый важный факт сначала пишется в подходящий документ в `docs/`, потом сюда одной строкой со ссылкой.
